How this solves the “archival graveyard”
  • Searchable: semantic search across English + regional scripts, not filename lookups.
  • Spatial: every record is geotagged; routes and folklore live on one map.
  • Immersive: photos become 3D twins that anyone can rotate in the browser.
  • Living: new field notes go straight into the archive, no more dead slide decks.
Production stack

Next.js + Three.js frontend · Mapbox GL · FastAPI service · PyTorch OCR (TrOCR-style) · OpenCV/COLMAP reconstruction · PostgreSQL + pgvector for semantic search. This demo runs the search, map, 3D and OCR flows client-side.
